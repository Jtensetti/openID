# SPAR customer-test responses

These fixtures contain only the published fictitious test persons from SPAR
Personsok 2023.1, cases 3.1, 3.12, 3.16, 3.18, 3.20, 3.21 and 3.24.
They are recorded customer-test responses, not production registry evidence.
No client key, certificate or actual passport is included.

Sources: [API and example](https://www.statenspersonadressregister.se/master/start/teknisk-info/personsoek/),
[customer test](https://www.statenspersonadressregister.se/master/start/teknisk-info/kundtestmiljoen/),
[published cases v9.1](https://www.statenspersonadressregister.se/media/zl2lun1q/testfall-foer-personsoekning-i-kundtestmiljoen_v91.pdf).

Names containing digits cannot be produced by the real authenticated passport
parser. A matching test query does not establish a real passport/person binding.
